# Apartmani Elegance Tuzla

Live site: https://apartmanielegance.ba

Static HTML/CSS/JS, originally exported from Webflow (April 2024). Hosted on Vercel.

## Structure

- `index.html` — homepage
- `deluxe-apartman.html`, `dvosoban-apartman.html`, `dvosoban-apartman-sa-dnevnim-boravkom.html`, `trosoban-apartman.html` — apartment pages
- `rezervacija.html` — reservation form
- `404.html`, `401.html` — error pages
- `css/`, `js/`, `images/` — assets

## Deployment

Auto-deploys to Vercel on push to `main`. Preview URLs on every PR.

## SEO + AEO project docs

Project planning + audit + lessons live in the workspace at `vibe-coding/projects/apartmani-elegance/docs/`. This repo only contains what gets deployed.
